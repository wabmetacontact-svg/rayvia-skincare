# Rayvia Skincare E-Commerce Website

Modern, high-performance E-Commerce platform for Rayvia Skincare built with Next.js 16, Turbopack, Tailwind CSS, and Drizzle ORM.

## Features
- **Storefront**: Responsive luxury UI, Product Catalog, Product Details, Cart, Checkout, Order Tracking.
- **Admin Control Center**: Product Management, Order Management, Coupon System, Reviews, Newsletter Subscribers.
- **Image Upload**: Built-in Admin Image Uploader for Main Image & Gallery Images.
- **Database**: Drizzle ORM with PostgreSQL support & PGlite fallback for local dev.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
